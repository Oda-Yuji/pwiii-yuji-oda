# pwiii-yuji-oda

### Configuração de Projetos Laravel Clonados
Crie uma pasta em C:\Users\Me e clone o projeto/repositório nela.

Abra o terminal do projeto e rode

    npm install

Seguido de 

    composer install

Enfim

    npm run dev

Se tudo correr bem, o projeto deve estar funcionando. Mas não se esqueça das migrations

    php artisan migrate


### Criação de uma API Java com Spring Boot
Abra o Spring Initializr em: https://start.spring.io/

Selecione o tipo de projeto, nesse caso: Maven

Selecione a linguagem: Java

Selecione a versão do Spring Boot a ser utilizada

Altere os dados do projeto: grupo, artefato, nome, formatação, configuração e a versão Java

Por último, selecione as dependências que serão utilizadas e crie o projeto em: GENERATE
